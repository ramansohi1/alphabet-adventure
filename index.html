How these observations work

Pencil marks outside the guide can be free exploration. Observations begin when the child reaches the current stroke. Screen tracing is not an assessment of independent handwriting. Speed is never a goal.

Practice settings

Sky: tall letters. Plane: small-letter height. Grass: where letters sit. Worm: where tails go. Tap a line name to hear about it.

Voice: automatic English

Watch demonstrates the whole letter. Hint lights up the current stroke without taking over. Trace fills a broad guide. Pencil shows the child’s own thin line. More wiggle room accepts wider movements; closer tracing asks for more precision. Pencil restarts the letter after four attempts with little progress, twelve unsuccessful attempts overall, or a very long scribble. Successful strokes and ordinary finger lifts are not mistakes. Try the same letter on real paper together too.
